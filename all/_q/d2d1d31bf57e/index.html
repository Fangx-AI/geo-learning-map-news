    搜索竞技场：分析搜索增强型大语言模型

    搜索增强型语言模型将网络搜索与大型语言模型（LLMs）结合，以提高响应的依据性和时效性。然而，分析这些系统仍然具有挑战性：现有的数据集在规模上有限，范围狭窄，通常仅限于静态的、单轮的事实核查问题。在本工作中，我们引入了 Search Arena，这是一个众包的、大规模的人类偏好数据集，包含超过 24,000 对使用搜索增强型 LLM 的多轮用户交互。该数据集涵盖了多样化的意图和语言，并包含完整的系统记录，其中约有 12,000 个人类偏好投票。我们的分析表明，即使被引用的内容并未直接支持所述声明，用户偏好仍然会受到引用数量的影响，揭示了感知可信度与实际可信度之间的差距……
