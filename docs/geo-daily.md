# GEO 日报与今日重点

当前阅读体验见 [产品路径](geo-reading-product.md)。`/` 是统一的今日重点，`/daily` 跳转到首页；`/library` 提供跨日期完整中文解读，旧 `/daily?view=library` 保留关键词等查询条件跳转。

今日重点按三个区块展示：近 24 小时的原文变化、北京时间当日首次补齐的解读、历史参考。旧文不因刚收录而变成新闻，修订旧概要不重新算作今日补齐。每条保留原文日期。卡片展示结论和选读理由，点击阅读数据、限制与本站行动建议。无完整概要的来源仍可从全部动态访问，主阅读路径不将其包装成完整文章。

数据复用 publication 的 `loadGeoDailyCandidates` 和 `GET /api/geo/daily?view=library`。阅读不会触发采集、翻译或模型调用；缓存最多 60 秒。主页面只展示有效的 reviewed、full-article、非自动概要；补充性理论研究不优先展示。候选上限 2,000，不宣称全网或全库覆盖。

后端日报接口 `GET /api/geo/daily` 保留近 24 小时与今日首次补齐两种时间窗口。去重沿用 canonical 身份及同语言长标题，不合并同主题的不同研究，不宣称事件级语义去重。私有证据、正文和 hash 不公开；停用来源不参与新读取。

`/daily/archive`、`/daily/YYYY-MM-DD` 和 `?day=YYYY-MM-DD` 保留按原文日期归档。未知日期明确标注，历史按收录时间归档不等于原文发布时间。

`/daily/editions` 列出整期报告。报告页默认显示已经逐条核读原始来源的解读，完整原始报告（包括目录、末尾及来源引用）可通过“原始整期报告”打开。完整收录不等于已逐项核验，原始文本不因展示层改变而改写。同步协议见 [整期日报同步](geo-editions.md)。
