# GEO 日报

2026-10-18：`/daily?view=library` 提供跨日期的中文解读资料库，接口为 `/api/geo/daily?view=library`。该模式 `view=library`、`recent=[]`，`research` 为通过筛选的历史完整解读；`briefAddedAt` 仍仅在确实当天首次补齐时有值。默认日报规则保持双时间窗口。卡片展示首条关键发现，完整发现与范围移至阅读页；搜索和展开状态保留在返回地址。三篇已核读的理论/模拟方法论文改作补充资料，不再进入日报重点。详见 [本轮验收](geo-reading-ux-20261018.md)。

`/daily` 为实时阅读摘要，通过 publication 的 `loadGeoDailyCandidates` 读取，公开接口为 `GET /api/geo/daily`。页面不会发起外部采集、翻译或模型调用。公开采集与概要补齐继续使用既有后台流程，日报在再次加载时纳入有效结果，缓存最多 60 秒。

- **近 24 小时重点**：按原文发布时间滚动计算，排除未来日期和未知日期，不以收录时间把旧文变成新消息。
- **今日补齐的研究**：按北京时间的概要首次创建日期，要求有效快照、reviewed、full-article。研究与官方解读均可进入，但来源目录标签不决定入选。修订旧概要不会重新算成今日新增；今日新闻同时有新概要时只在第一栏出现。
- **筛选**：沿用内容规则，排除聚合索引、明确营销、转载、汇编和转发线索。社区帖须有作者自行测试与方法线索。有效的核读概要可补充短 RSS 摘要缺失的 GEO 相关性证据。没有完整概要的新消息仍明确显示“来源摘要”，不编造结论或 GEO 收益。
- **去重**：先按 canonical 身份，再按同语言归一化长标题（至少 18 字符）跨栏合并，优先直接出处及已核读概要。同主题的不同研究不合并，不宣称已实现事件级语义去重。不同域名轮流展示，避免单个高产来源占满首屏。
- **阅读**：默认中文；展示核心结论、GEO 价值与必要范围，数据和发现通过原生 details 展开。每栏先显示 6 篇，按钮显示其余真实篇数；中原切换、收藏、站内阅读及原文链接保留。新入口没有重复桌面导航、采集元数据或评分说明。

候选从整个启用信源集合按两个时间条件读取，不依赖旧 overview 的最近 4,000 条。候选上限 2,000，触顶时页面明确说明；所有摘要均复用单条阅读接口的精确 input hash 与 schema 校验。私有证据、正文、hash、canonical 身份不出现在接口响应。停用来源立即不参与新读取。

`/daily/archive`、`/daily/YYYY-MM-DD` 和 `?day=YYYY-MM-DD` 保留原文日期归档，以免旧链接、日期选择和回退行为改变。它们不是历史日报快照；当前双栏日报也不是每天冻结的期刊，不伪造历史期号。
