# 资讯首页改版（2026-10-22）

站点定位是全球 GEO 与 AI 搜索的一手资讯。上一版首页只放已核读的完整解读，库里大多数资讯进不了首页，读者打开后看到的是几篇旧研究；全部动态里又混着服务商软文和榜单。这一版把“今天发生了什么”放回首页，并默认折叠软文、榜单和转载。

## 页面

- `/`：今日 GEO 资讯。头条取概览的精选（不含社交帖子，平台官方和平台变化在前，论文最多一篇），下面是最新资讯（文章，按北京时间分天），侧栏是近期被多个来源报道的平台、最新深度解读和日报入口。顶部按平台进入 `/topics/:slug`。
- `/all`：最新资讯，默认按时间、只看文章、折叠软文和榜单。“媒体报道”是 Google News 等聚合索引里的各国媒体报道，和社交帖子、全部类型一样一键切换；来源、语言、发布平台和排序收在“更多筛选”里。`?quality=all` 显示被折叠的内容。
- `/library`：深度解读，即原来的已核读完整解读库，筛选和关注不变。
- 导航：首页、最新资讯、深度解读、平台与主题、日报、收藏。热点榜、往期日报、关注和信源目录在“我的”工具里，原链接都可访问。
- 卡片：价值标签（官方、平台变化、一手数据、研究、论文）、涉及的平台、标题、两行摘要、来源、时间、原文链接和收藏。相似标题合并为“另有 N 条相似报道”，展开后每条都保留链接和独立收藏。

## 价值判断

- 阅读策略版本 4（`industry/public-reading.ts`）新增 `platformSignal`：ChatGPT 广告与购物、AI 爬虫与 bot、按次付费抓取、智能体购物、Search Console、Webmaster Tools、AI visibility、商家资料、核心更新与垃圾政策等平台变化。它同时进入公开收录（`relevance.ts` 的“AI 与搜索平台变化”）和阅读优先级。真实样本里 “Merchant Center” 会把 Google Ads 资讯误判为平台变化，已去掉。
- `readingPriority.badge` 由同一份事实计算：arXiv 为“论文”，平台官方域名为“官方”，研究且有一手数据为“一手数据”，其余研究为“研究”，平台变化为“平台变化”；降级（rank 2）的条目没有标签。
- `readingPriority.folded` 标出服务推介、选型榜单、汇总播报和明确转载。`GET /api/geo/public-items?quality=useful` 在数据库里去掉这些条目，`hiddenTotal` 返回去掉的条数；默认 `all` 与原来一致。游标绑定 `quality`。只是关联较弱或来自聚合索引的条目仍是降级（rank 2），排序靠后，但不折叠：真实样本里它们有不少是平台官方说明、各国媒体报道和实测。
- 概览的精选只取 rank 0 和 1；主题分组和热点聚合不使用被折叠的条目。

## 验证

用 57 个公开订阅的 2,640 条真实条目（本地种子库，不开采集和模型调用）对比改动前后：公开收录从 770 条变为 827 条，新增 57 条、没有丢失，新增的是 ChatGPT 广告与购物、Atlas、智能体购物、Cloudflare AI 发现与 Verified bots、Search Console 与 Bing Webmaster Tools、站点信誉与垃圾政策、核心更新等平台变化；优先阅读从 58 条变为 89 条，24 条原先降级的平台变化回到标准或优先。被折叠的是 21 条，其中 17 条是 “Best GEO agencies / 服务商推荐” 类榜单、展会和服务推介，另有两条社交帖子、一条 Semrush 试用指南和一篇提到“代运营”的评论文章（误判，已知）。复核中修正了三处误判：“ChatGPT ad” 命中 “ChatGPT adoption”，“top” 命中 “Topics”（把 Bing 官方的 AI Visibility 更新当成榜单），“Merchant Center” 把 Google Ads 资讯当成平台变化。新增的六个样本放进 `modules/geo-directory/tests/quality-fixtures.ts`。浏览器测试覆盖首页无 JavaScript 渲染、筛选与分页保留、内容类型切换、折叠视图、相似标题展开、未知日期和排序切换。

## 局限

价值标签和折叠都是规则，不是人工编辑或事实核验；没有标签不代表不重要。“今天 / 昨天”按北京时间显示。资讯量取决于已开启的采集；未开启采集的新部署首页仍然是空的。
