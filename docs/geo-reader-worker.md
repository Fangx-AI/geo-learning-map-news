# 站内概要持续补齐

概要在后台读取完整公开 HTML 正文，生成中文结论、关键发现、GEO 启示和必要限制。完整正文、段落证据、模型检查记录都只存在私有任务表；公开接口仍只提供短概要和原文链接。页面请求不会触发模型。

## 运行

- `PUBLIC_READER_BRIEFS_ENABLED=true` 开启私有草稿生成。
- `PUBLIC_READER_BRIEF_PUBLISH_ENABLED=true` 额外开启自动复核与发布，默认关闭。每项事实和启示都须通过数值检查及单独的语义核查。失败或未覆盖核心信息不发布。自动生成的内容在核心结论旁标注「AI 整理」。

安装模型并设置本机 `.env` 后，运行现有公开采集守护：

```powershell
node --env-file=.env modules/geo-directory/scripts/setup-reader-brief.ts
node --env-file=.env modules/geo-directory/scripts/watch-public.ts
```

已运行的守护进程不会重新读取 `.env`；修改配置后需核验并重启本项目的守护和采集子进程。一键启动只补启动缺失服务，不会替换健康的旧进程。

每次处理一篇，复用已加载模型，完成后等待 5 秒；无候选时释放模型并每分钟检查。采集和短摘要翻译按各自计划运行。电脑、数据库及守护需保持运行；电脑重启后使用 `scripts/start-geo.ps1` 恢复，目前不安装开机任务。

受控运行一篇或一批：

```powershell
node --env-file=.env modules/geo-directory/scripts/draft-reader-briefs.ts --once --limit 3
node --env-file=.env modules/geo-directory/scripts/draft-reader-briefs.ts --once --item 64位条目ID
```

## 处理顺序

1. 沿用现有阅读质量等级，排除被降权条目；同等级优先已有目录中的官方与研究信源，再按新旧排序。不改变网站评分门槛。相同 canonical 原文只处理一次。
2. 经受保护的 HTTP 抓取和 Readability 提取完整公开正文，不跨登录、付费墙或验证页。确认最终 URL 和 canonical 属于同一文章；表格保持行列分隔。arXiv 摘要页及 HN 讨论页不进入全文概要队列。
3. 用实际模板与 tokenizer 检查完整输入，装不下记录 `too_long`，不截掉后半篇。概要目标 300–450 字，保留结论、主要数据与实际价值。
4. 每项须有段落证据，检查数字、百分比、百分点及结构完整性。失败时最多修订一次；英文月份可以忠实转换为中文数字月份。
5. 自动发布开启时，再用新的核查角色逐项比对原文，检查数字对象、比较方向、相关与因果、产品能力和研究范围，并检查核心信息是否遗漏。失败时最多再修订一次，然后重新复核；仍不通过留为私有草稿。
6. 发布前再次核对来源状态及精确输入版本。自动结果不能覆盖独立审核版本，正文及核查过程不进入公开出口。

复核仍是模型判断，不能保证零错误，仍需真实样本抽查。图片内部数据没有 OCR；无法读取的内容不猜补。失败条目不会用空壳或开头摘句冒充完整概要。

## 重试与恢复

模型缺失或服务不可用时全局退避。单篇推理超时单独记录 `timeout`，不冻结整个队列。403/429 按主机冷却并遵守更长的 Retry-After，403 至少一天；普通失败从一小时递增，最长七天；超长、受限正文等等待七天。

模型失败可复用私有正文。七天刷新时重新读来源，正文、模型和提示词版本未变则复用草稿。自动核查拒绝也保留在私有队列，避免连续重写同一篇。

任务有数据库互斥锁，失锁或停止进程会取消请求并关闭自有模型。来源变化后不保存旧结果。日志区分 published、review-pending、drafted、failed、stale；ready-draft 不等于已发布。

安装参数和真实验收见[本地模型](geo-reader-model.md)。


## 定时核读补齐

2026-10-17 在当前 Codex 聊天配置了“GEO 中文概要持续补齐”（自动化 id：geo），每 30 分钟触发一次，每轮目标为核读并发布 3–5 篇高价值待补内容；实际数量取决于可获取正文和核验结果。Codex 对照完整公开原文后写入 reviewed 概要，不表示人工审稿。原文快照和证据保持私有；只抽查本轮条目，不反复改页面或重跑无关测试。执行依赖电脑与 Codex 运行及可用额度，不能当作关闭电脑后的云端服务。当前进度见私有 .data/reader-brief/progress.md。

本地小模型反复出现误读、漏引或错误拒绝，实际自动发布为 0。用户要求不要继续卡在重试后，本机已设置 PUBLIC_READER_BRIEFS_ENABLED=false 并核验重启采集守护，使概要推理暂停；公开采集和短摘要翻译继续运行，已有私有草稿和模型保留。定时核读任务已明确不启动小模型、不反复改提示词，优先实际发布合格内容。不把生成草稿数当成公开完成数。
