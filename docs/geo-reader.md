# 站内内容概要阅读

2026-10-18：新增 `/daily?view=library` 中文解读资料库。公开列表以 `readingReady` 标明当前是否有有效、已核读的完整概要，精选、主题、归档与全部动态统一校验。无完整概要的阅读页明确提示范围，并链接至已完成的解读。详见 [阅读体验修复与验收](geo-reading-ux-20261018.md)。

精选、全部动态、主题、日报、热点展开项和 GEO 收藏的主标题进入 `/read/:id`，配图与标题使用同一站内链接。原始外部 URL 继续保存在条目和收藏中，只在阅读页作为可选的“查看原文”入口。

阅读页默认显示中文概要：核心结论、关键发现、对 GEO 的启示。数字随文说明样本、时间、分母；本站解读与原文发现分开，实质性限制直接可见。依据论文摘要而非全文整理的内容明确标注范围。无完整概要时仍显示原来的来源摘要，不把导语改名为全文综述。页面不嵌入第三方网站，不因点击触发抓取、模型或翻译请求。

概要与来源摘要是独立内容。概要页的“原文摘要 / 中文概要”切换不打开外链；“查看原文”保留作者链接。概要不覆盖原始摘要、已有译文或旧收藏；进入旧收藏的站内阅读页会读取当前概要。译文纠错仍作用于来源标题和摘要，在来源摘要模式可用，不把译文修改误当成概要修改。

单条 HTTP 接口为 `GET /api/geo/public-items/:id`，返回 `{ item }`，统一通过 publication 读取层取得公开投影。可选 `item.brief` 只含 `conclusion/findings/geoValue/caveats/coverage/updatedAt`，自动稿另有 `automated:true` 并显示“AI 整理”；列表负载不添加概要。只读取已启用来源，保留原始条目身份；有效的已审核纠错优先于机器译文，过期译文不展示。不会返回原始正文、私有证据、摘要缓存、采集游标或后台错误。合法 ID 不存在或来源停用返回 404，无效 ID 返回 400。

概要存于模块表 `geo_public_reader_briefs`，通过 `sha256(JSON.stringify([url,title,summary ?? null]))` 绑定精确来源快照。任一原文字段变化后旧概要隐藏，写入采用事务检查快照；自动结果不能覆盖已审核版本。审核材料只保存在私有证据字段，不通过公开接口发布。短概要需要中文结论、关键发现和独立 GEO 启示，不能提交空占位或全文 HTML。

核对原文后可用本地 JSON 数组导入，先执行默认预检，再带 `--write` 保存。每项包含 `id/inputHash/sourceUrl/brief`，可选 `bodyHash/evidence`；没有持有规范化正文时不伪造 `bodyHash`。

```powershell
node --env-file=.env modules/geo-directory/scripts/import-reader-briefs.ts .data/briefs-reader-reviewed.json
node --env-file=.env modules/geo-directory/scripts/import-reader-briefs.ts .data/briefs-reader-reviewed.json --write
```

从列表进入时把当前站内路径与查询放在 `from`，并记录站内导航状态。常规返回回退到原浏览历史项，保留筛选和页码；直接打开或新标签页打开时使用经过白名单验证的站内 `from`，缺省回到全部动态。外部 URL、协议相对 URL、反斜杠和非阅读列表目标不作为返回地址。

GEO 收藏通过模块提供的可选 `starredItemHref` 选择站内阅读地址，原始 URL、收藏 ID 和已有导出格式保持不变；没有提供该能力的模块和其他外链收藏沿用原行为。

后端解析历史 canonical ID 后会返回当前条目的实际 ID。阅读页同时识别后端已验证的请求别名和实际 ID，已有旧收藏仍显示“已收藏”；取消时只删除这两个已存在的关联 ID，不生成重复收藏，也不主动改写其他收藏及保存时间。
