# 阅读体验改版（2026-10-20）

## 默认路径

- `/` 是唯一今日重点；`/daily` 跳回这里。按原文发布时间区分近 24 小时变化、今日新补齐与历史参考，不用接口请求时间冒充内容更新时间。
- `/library` 按工作问题与关键词查找已核读完整解读，旧 `/daily?view=library` 保留筛选跳转。主题、热点、来源目录和历史日期仍在“我的”工具及原链接可访问。
- `/following` 保存关注的工作问题和阅读记录。打开不等于读完，明确标记后才计为已读，概要版本变化后重新显示未读。仅在本浏览器保存，最多 100 条记录，无账号或跨设备同步。
- 阅读页分开标注来源发现与本站建议；提供检查步骤、验收口径和术语解释。检查建议不是研究测得效果，更不能保证排名。原文与完整已核读概要、收藏和中英切换继续保留。
- 整期报告默认显示已核读来源的结论与 GEO 启示；原始完整报告通过独立阅读方式打开，完整正文与章节均保留。尚未核读的报告不能冒充已验证观点。

## 编辑与数据边界

`industry/reading-guide.ts` 维护问题分类与人工选读理由，不改变采集评分门槛。无人工理由的条目只展示阅读方向。分类依赖内容关键词，不能代替编辑判断。纯理论及已标记的补充研究不进入优先阅读队列。

核读全文不等于本站独立复现实验。解读库只展示完整非自动概要；摘要不足的来源保留在全部动态，明确提示缺口。完整报告原始文本不因 UI 改版而改写，数据、私有证据和聊天 ID 不进入开源代码。

## 验证

覆盖旧链接跳转、查询保留、无 JavaScript 阅读、手机溢出、关注持久化、未读/已读/更新状态、存储失败、原报告全文可达、来源日期与链接，以及返回与缓存到期行为。真实本地站点按桌面 1440px 与手机 390px 检查首页、解读库、关注、阅读页及整期报告。

仍需持续编辑补齐完整概要；页面结构优化不会自动增加已核读内容数量。关注属于阅读辅助，不提供后台推送或跨设备同步。
