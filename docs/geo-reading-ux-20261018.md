# 从来源目录走向可直接阅读的产品

用户反馈：入口难理解，点击后内容不齐全，阅读费力。本轮依据真实接口、路由代码和浏览器回归修复，未将截图工具不可用的实机视觉检查说成已通过。

## 已实现

- `/daily?view=library` 是中文解读资料库。读取所有日期的有效 reviewed/full-article 概要，沿用来源启用、精确原文快照、schema、降噪和去重检查；不以今天新写的数量冒充今天新发生的新闻。当前候选上限 2,000，触顶说明仍展示。
- 日报提供“今日重点 / 中文解读”两个明确入口。卡片直接展示结论、第一条关键发现、第一条 GEO 启示和首条适用范围；其余发现与范围保留在完整阅读页，不截断或改写原有概要。
- 资料库搜索中文标题、原文标题、来源、结论、发现和 GEO 启示。搜索词和展开状态存入 URL；阅读链接带回原地址，返回时复用既有历史和滚动恢复机制。
- 全部动态、精选、主题和归档列表使用相同快照校验返回 `readingReady`，区分“中文解读 / 来源摘要”。列表不发送全文或私有证据。阅读页明确材料范围；没有概要时提供已完成内容入口，不承诺不存在的全文。
- 修复客户端 `/daily.data` 被误判为旧归档页的问题。SSR 与客户端切换现在走同一日报分支。
- 依据已经核读的具体内容，将 Conversational Capture、VCR、Gap Detection 三篇理论或模拟研究移出日报重点；资料库保留，并后置。具体文章例外存于 `industry/reader-curation.ts`，不把 arXiv 标签一概降权，不修改模型五维评分或门槛。
- 既有定时任务取消“每轮 3–5 篇”配额，优先真实平台实测和有 GEO 影响的官方变化；没有合格内容允许零新增。

## 产品定位与下一步验收

目前是中文 GEO 情报阅读站，还不能称为顶尖咨询平台。不应使用“完成百分比”或无依据工期来掩盖差距。

| 缺口 | 对用户的影响 | 下一步验收标准 |
| --- | --- | --- |
| 完整解读覆盖有限 | 来源数量多，但能直接看懂的少 | 核心阅读入口优先完整内容，缺口在点击前可见；持续记录真正可读条数 |
| 证据层级未系统化 | 理论、受控实验、线上观察、官方规则容易混淆 | 逐篇核对研究类型、样本、时间与适用范围，不用来源名替代证据判断 |
| 只做文档去重 | 同一事件的转载仍可能分散注意力 | 事件页合并多个出处，保留差异和矛盾，而不是合并不同研究的结果 |
| 缺少用户自己的问题背景 | 通用 GEO 启示不等于可执行咨询 | 围绕目标平台、行业和目标指标给出有依据的下一步，并可回看验证 |
| 缺少独立测量资产 | 大部分结论依赖来源 | 建立可复查的固定查询和重复测量，明确观测与因果边界 |
| 尚无真实用户可用性验证 | 工程测试通过不代表容易使用 | 观察用户能否找到一条相关解读、说清结论与限制、返回继续阅读；记录失败点 |

本轮没有为增加数量发布新论文，也没有把 UI 改动当作内容已经补齐。完整概要是原创中文解读，不是第三方全文转载。

## 验证结果

- 真实公开接口：来源动态 1,646 条；资料库 86 篇，全部为当前有效的 reviewed/full-article 内容。抽查前三篇，资料库、单条 API 和阅读页结论一致。此数为当前筛选结果，不等于全部已存储概要数量。
- TypeScript、生产构建、站点 smoke 通过。网页全套 108 项首次 106 通过；其中日报客户端路由错误已修复，相关网页 27 项最终全部通过，覆盖移动端、搜索、展开状态、返回链接、中原切换与站内概要。
- 日报独立回归 5/5，最终隔离数据库相关回归 15/15；覆盖历史概要、停用来源、过期快照、列表/单条字段一致性与私有字段隔离。
- 后端全套 1,066 项首次 1,056 通过。新增阅读状态字段的契约用例已修正并复测；出站协议使用本机 Git 自带 OpenSSL 复测通过。仍有 8 项备份用例缺少 `pg_dump`，未声称全套通过。各轮自有测试库清理完成。
- API 与网页已更新；数据库和公开采集守护复用，采集状态 waiting、最近一轮完成且无守护错误；未启用暂停的小模型概要队列。
- Codex 内嵌浏览器工具报 `failed to write kernel assets`，未取得本轮真实页面截图。因此本轮只确认浏览器功能回归与真实 HTTP 内容，尚未完成实机视觉审查或真实用户可用性测试。

日志：私有 `.data/ux-*`。本报告不是“完美 UI”或顶尖咨询能力的验收证明。
