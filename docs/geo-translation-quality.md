# GEO 标题与摘要翻译质量评测

2026-10-16 抽查；数据库只读快照时间：`2026-10-16T14:22:11.812Z`。

当前最影响阅读的是术语选错、短摘要截断后补出不存在的事实，以及专有名称和社交标题前缀处理失误。不是所有生硬译文都需要重写：已正确保留数字、否定和限定的内容，应作为回归测试的正例保留。

## 样本与可使用范围

评测集：[translation-examples.jsonl](../industry/translation-examples.jsonl)。26 条，23 个采集信源名，摘要长度 0–361 字符；全部取自当时有效的 `bing` 翻译。先选 20 条覆盖不同语种、长短摘要与内容类型，再补 6 条首页相关材料，重点检查 Ahrefs、Discover、查询扇出、点击和展示次数。

语言标签为 `en` 17、`und` 1、`de` 1、`fr` 2、`ja` 2、`ko` 1、`pt` 1、`es` 1。`und` 样本实际为英文。这是有目的的覆盖/排错抽样，不是随机样本；下列数量不能推算全站错误率。

| 评估 | 数量 | 用途 |
| --- | ---: | --- |
| `meaning_error` | 11 | 有具体语义、关系、名称或事实增添问题 |
| `incomplete` | 3 | 标题正文被错误当作前缀保留，未完整翻译 |
| `style_only` | 7 | 原意基本成立，仅文风、命名或段落边界可改善 |
| `acceptable` | 5 | 数字、否定、限定或缺失摘要的正例 |

每条保留原文、当时译文、来源网址、翻译时间、原文版本哈希和参考译文。`publishable:true` 的 14 条只表示有明确纠错价值且提供了完整短摘要参考，仍需主任务逐条复核后发布；不是来源事实已经核实的标记。其余 12 条不应自动覆盖现有译文。参考翻译只覆盖库内已有短摘要，不补文章被截断后的未知内容，不把研究假设、作者判断、专利描述变成平台已上线的事实。

主任务逐条复核后，02（GSQi）与 21（Ahrefs）的参考摘要移除了已核对的 Read more / The post RSS 导航尾注，保留内容截断省略号；原始采集摘要未改动。这两条另有 `editorialCleanup: ["verified_rss_navigation_tail"]` 标记。此处是导航尾部清理，不是补全缺文。

## 正确翻译也要保留

- **09 · Brodie Clark**：原文“没有点击量和查询，只有展示次数”、约 6 月 13 日均保留。不能把旧报道改写成平台当前状态，也不能把 impressions 换成点击量。
- **10 · Lily Ray**：约 100 个查询、较 6 月少 38%、83% 对比 69% 都正确。“少 38%”不是“下降 38 个百分点”。不要自行加入原文未计算的 14 个百分点。
- **15 · 日语 PDF**：疑问标题、播客第 115 集及讨论主题准确。标题提问不等于文章已经证明 PDF 会被 AI 引用。
- **19 · 西语 Human Level**：原文没有摘要，参考摘要保持 `null`，不能为了卡片整齐编造摘要。
- **20 · SE Ranking**：标题“超过 52%”与摘要“每两次查询一次”的差异来自原文的近似表达；保留 10 万次分析样本，不扩展为所有搜索的普遍规律。
- **25 · HN**：Clicks / Impressions / Positions 对应“点击量 / 展示次数 / 排名”。原始摘要只有文章链接、评论链接、分数和评论数，不能凭标题生成文章摘要。

## 术语依据与边界

- Google 官方中文文档使用“查询扇出”“AI 概览”“AI 模式”。英文 AI Overviews / AI Mode 可以与中文并列以利检索，但现有正确官方中文译名不是错误。[Google：AI 功能和您的网站](https://developers.google.com/search/docs/appearance/ai-features?hl=zh-cn)
- manual action 的官方中文为“人工处置措施”，其语义不同于普通人工操作。[Google Search Console：人工处置措施报告](https://support.google.com/webmasters/answer/9044175?hl=zh-Hans)
- Bing 官方将 Sites Cited 定义为主题相关查询中出现的网站数量指标，故方向是“被引用”，不是这些网站引用该主题。[Bing：Introducing Topics Portfolio (Beta) in AI Performance](https://blogs.bing.com/webmaster/2026/10/introducing-topics-portfolio-beta-in-ai-performance/)
- Transactive Memory 在所选论文中用于多智能体共享与复用知识；“交易记忆”会让人误读。参考采用“交互记忆”并保留原词，不宣称这是作者指定译名。[arXiv：Multi-Agent Transactive Memory](https://arxiv.org/abs/2606.19911)

术语一致性应在不改变原文的前提下实现。GEO 在当前站点语境应保留缩写，不能自动展开为地理信息；未知姓名保留原拼写；Discover、Search Console、Substack、PubMed 及模型名不得随意按普通单词翻译。正文内链接、百分比、否定词和 may/can/seems 等确定性要与原文逐项对应。

## 后续产品路径

以下记录 2026-10-16 本轮落实情况；前面的评测样本、原文与当时译文仍保留为历史快照，不代表当前线上内容。

### 1. 以真实误译为驱动的发布质量门槛

本轮已加入已知漏译前缀、原文没有的年份、数字百分比遗漏检查及有语境约束的术语修正，并用参考译文修复了选定的语义问题。下一步可扩展到“丢失否定”“未知姓名汉字化”和数值关系等问题。先用本评测集的错误与正例验证，不因中文是否流畅就整批覆盖。仅凭数字字符比较不足以完成此事：100,000 与 10 万等价，38% 与 38 个百分点不等价。

验收：21 不能出现 2023；08 不补出条件；09 的否定和 only 不丢；10 的比较单位不变；19 仍无摘要。术语与后处理须带版本，只重译受该版本影响的记录，并绑定原文版本，避免旧译文覆盖新摘要。

### 2. 已实现：极简“纠正译文”入口与版本保护

专有姓名、隐喻标题和“引用/被引用”这类关系问题，不是一个词表可以完全解决的。阅读卡片与收藏已提供“纠错”入口，可对照原文修改中文标题、摘要并填写可选说明。提交只生成待审核建议，不立即替换当前译文；后台审核后，以绑定原始标题、摘要和语言的覆盖层发布，后台重译不会覆盖同一原文版本已经确认的修正。原文变化后旧修正失效，不能仅凭条目 ID 或相似标题套用。原文无摘要时，纠错入口也不会允许凭空新增摘要。

审核仍需区分文风调整与事实、语义错误；功能上线不等于所有历史样本都经过人工审核。版本保护保证已审核的同文修正不被自动重译覆盖，来源摘要变化时旧修正不再生效。

### 3. 已实现：在采集端提高“可翻译摘要”的完整度

13 的法语专利摘要在引号内截断，02、09、21 混入 Read more / The post 等 RSS 尾注，25 完全是 HN 链接与计数。采集端现已按来源移除经过实测的固定尾注，并以英文约 900 字符、中日韩文字约 450 字符为上限优先保留完整句子；原始摘录、读取入口及形成版本另行保存以供核对。历史回填累计更新 192 条，其中 162 条摘要文本变化，原文链接、标题和时间保持不变；摘要变化后旧译文失效，由后台重新翻译。实现、真实来源对照及应用结果见 [公开摘要形成与历史恢复](geo-summaries.md)。

边界：按来源匹配尾注，正文里的同样词语保持原样。来源自己只提供 teaser 或半句话时仍保留省略号，无法从更长的本站预算恢复缺文；原文没有摘要就保持为空，HN 链接与计数也不改写成文章内容。仍只展示短摘要与原文链接，不以机器补写未知后半句。

### 4. 已实现：收藏同步已经确认的译文纠错

收藏现已接入共享译文更新机制。中文模式下，会读取与收藏中原始标题、摘要、语言匹配的有效译文，将后续确认的修正同步到收藏；支持旧收藏中已解码文本的兼容匹配，不仅依赖条目 ID。原文已变更、条目不可用或网络中断时保留原始收藏快照，不把新摘要的译文套进旧内容。同步不覆盖用户备注、不改变原链接，也不要求新增账号。

同一原文版本的纠错审核通过后，收藏可获得新译文；切换原文模式不会丢掉已经读取的中文。收藏的原文版本与线上内容不一致时，不自动替换其内容快照。

摘要形成、历史回填、收藏译文同步和审核式纠错入口已在本轮实现。后续重点仍是更深入的语义检查，例如否定、未知姓名与比较关系；必须同时用错误和正确样本验证，不能把语言流畅当成事实忠实的证明，也不能承诺所有来源都有完整摘要。

## JSONL 使用约定

`referenceTitle` / `referenceSummary` 是语言参考，不是外部事实审核。离线修复只考虑 `publishable === true`，并同时校验 `itemId`、`contentHash`、`originalTitle`、`originalSummary`、`originalLanguage`；摘要使用 null-safe 比较。原文、网址、发布时间、排序分与分组键均不在本评测任务的修改范围。

本次验证：26 个不同 itemId；每条非空原摘要均有完整参考字段；原摘要为 null 的记录参考仍为 null；没有调用外部翻译服务，没有修改生产数据库。
