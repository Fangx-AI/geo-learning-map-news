# 接手说明

这是可运行的 GEO 资讯产品开发版本，不是已完成的咨询平台。优先让读者找到重点、看懂结论与证据，再扩充入口和采集量。

## 开发入口

- `apps/web`：React Router 网页；`apps/api`：HTTP API。
- `modules/geo-directory`：公开采集、排序、翻译、阅读概要和整期日报。
- `packages/backend/src/publication`：唯一公开读取层，不应泄露私有全文、证据或凭据。
- `industry`、`site`：GEO 信源、主题、品牌及导航。

按 README 初始化自己的环境和数据库。首次启动没有生产内容；公开采集与短摘要翻译须显式启用。私有数据库、抓取快照、聊天记录、收藏及自动化任务不在仓库内。完整概要不在打开页面时生成，核读导入见 `geo-reader.md`。

## 默认阅读路径（2026-10-20 更新）

1. 首页只展示最近完成的六篇已核读完整解读，可直接看到结论和 GEO 启示；入口通往今日日报或解读库。
2. 日报优先展示近期重点和当日新补齐的解读；仅有来源摘要的动态折叠显示，整期报告独立入口保留。
3. 阅读页按结论、关键发现、GEO 启示、适用范围组织，提供目录、阅读时长、语言切换、收藏及返回列表。缺少概要时明确展示来源摘要，并推荐已完成解读。
4. 桌面页面移除与侧栏重复的导航。侧栏复用已有访问缓存，避免焦点预取让返回列表额外等待。

仍需持续改进：已核读内容的覆盖率和时效；长篇整期报告的浏览效率；规则误收与遗漏。来源类型不能替代逐篇质量判断，完整解读也不等于独立复现实验。抓不到全文时不能把导语包装成完整解读。

用真实桌面和手机验收“首页→挑选→读懂结论、数据与限制→返回继续阅读”。同时检查空数据、无概要、旧收藏和原文缺日期。

## 运行和验证边界

公开抓取会遇到访问限制，不保证全网覆盖。机器翻译需要抽查；本地小模型概要质量不稳定，默认不要启用。自动稿不能覆盖已核读概要。整期聊天同步需单独配置授权来源和运行环境，见 `geo-editions.md`。

运行类型检查、网页构建及测试、隔离后端测试和 smoke。见 `geo-test-local.md`。Windows 本机完整后端测试需要另外配置 `pg_dump`、`pg_restore` 与 `openssl`；GitHub 检查环境已配置对应工具。历史文档中的测试数字属于当时环境，不代表新部署通过。保留上游 MIT 版权；第三方内容许可不随代码许可转移。
