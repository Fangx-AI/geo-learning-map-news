# 接手说明

这是可运行的 GEO 资讯产品开发版本，不是已完成的咨询平台。优先让读者找到重点、看懂结论与证据，再扩充入口和采集量。

## 开发入口

- `apps/web`：React Router 网页；`apps/api`：HTTP API。
- `modules/geo-directory`：公开采集、排序、翻译、阅读概要和整期日报。
- `packages/backend/src/publication`：唯一公开读取层，不应泄露私有全文、证据或凭据。
- `industry`、`site`：GEO 信源、主题、品牌及导航。

按 README 初始化自己的环境和数据库。首次启动没有生产内容；公开采集与短摘要翻译须显式启用。私有数据库、抓取快照、聊天记录、收藏及自动化任务不在仓库内。完整概要不在打开页面时生成，核读导入见 `geo-reader.md`。

## 当前产品问题

1. 首页、日报、全部动态职责和默认阅读路径需要更清晰。
2. 完整解读与仅有来源摘要的内容会造成不同阅读预期。
3. 整期报告篇幅较长，需要阅读层次和返回位置。
4. 规则筛选存在误收与遗漏，来源类型不能替代逐篇质量判断。

用真实桌面和手机验收“首页→挑选→读懂结论、数据与限制→返回继续阅读”。同时检查空数据、无概要、旧收藏和原文缺日期。

## 运行和验证边界

公开抓取会遇到访问限制，不保证全网覆盖。机器翻译需要抽查；本地小模型概要质量不稳定，默认不要启用。自动稿不能覆盖已核读概要。整期聊天同步需单独配置授权来源和运行环境，见 `geo-editions.md`。

运行类型检查、网页构建及测试、隔离后端测试和 smoke。见 `geo-test-local.md`。历史文档中的测试数字属于当时环境，不代表新部署通过。保留上游 MIT 版权；第三方内容许可不随代码许可转移。
