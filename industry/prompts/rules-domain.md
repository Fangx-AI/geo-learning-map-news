【GEO 领域术语与证据规则】

1. 按语境翻译，不把缩写机械解释成 AI：
   - GEO = 生成式引擎优化；AEO = 答案引擎优化；SEO = 搜索引擎优化。保留缩写，首次出现需要解释时用这些名称。原文若把 GEO 用作地理或其他含义，按原文处理，不能偷换。
   - LLM = 大语言模型；RAG = 检索增强生成；retrieval = 检索；grounding = 基于来源的信息支撑；citation = 引用；mention = 提及；visibility = 可见度。
   - crawling = 抓取；indexing = 索引或收录；ranking = 排名；referral traffic = 引荐流量；attribution = 归因；conversion = 转化；query fan-out = 查询扩展。
   - AI Overviews、AI Mode、ChatGPT Search、Copilot、Perplexity、Claude、Gemini、Grok、Le Chat、Brave Search、You.com 等产品名保留原文；国内平台采用原文品牌名，不把元宝、混元、豆包、千问、Kimi、文心混成同一个产品。
   - robots.txt、llms.txt、sitemap、Schema.org、JSON-LD、IndexNow、API、URL、HTML、HTTP、CDN 等协议和文件名保留原文。User-Agent、机器人名、命令、代码和网址一字不改。
   - Token 在模型语境可保留 token，在鉴权语境是令牌；Agent 在智能体语境译为智能体，User-Agent 不译成智能体。不把搜索检索、推理与训练混为一谈。

2. 严格区分观察和效果：
   - 能抓取不等于已索引，已索引不等于被引用；品牌提及、可见引用、引用位置、搜索排名、点击、引荐流量与转化不是同一个指标。
   - 来源被引用不证明来源全部正确，引用增加不自动证明优化有效。前后变化与相关性不能改写成因果。
   - 一个平台、一次会话、一个问题集或某种语言下的结果，不能推广为全部 AI 平台。保留平台/模型、搜索开关、地区语言、采样日期、问题数、重复次数、对照和统计口径中影响结论的条件。
   - “提升 20%”与“提升 20 个百分点”严格区分；引用占比保留分母与样本范围，数字单位不改写。
   - 官方文档能证明平台公布了某项规则；厂商公告能证明宣布或上线，不能自动证明营销效果。案例的自述、研究推断、个人假设和未独立复核的观察均明确归于提出者。
   - 不承诺被收录、被推荐、被引用或排名提升；不把 llms.txt、结构化数据、关键词堆砌、付费发稿或第三方工具分数写成通用保证。
   - 搜索抓取、用户触发访问和训练抓取按原文分开。不得声称允许训练就必然获得搜索引用，或禁止训练就必然从搜索消失。

3. 保留专名与版本：
   - 平台、工具、论文、数据集和研究作者的专名以原文为准。Ahrefs、Semrush、Profound、Peec AI 等厂商名不是效果背书。
   - 模型名、产品版本、日期、数字、单位、比例、币种与区间照原文；不要凭背景知识补写当前版本或发布时间。
   - 无法识别的小语种专名可保留原文，不猜所属公司或国家。观点与失败实验按实际主张翻译，不改成成功教程。
