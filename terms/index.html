1. 内容与来源

GEO 学习地图整理生成式引擎优化、AI 搜索与答案引擎优化相关的公开信源、中文摘要和阅读入口。目录覆盖持续扩展，不保证穷尽全球来源；目录收录不代表该来源已接入自动采集，也不代表本站认可或推荐其商业服务。

标题、摘要和关注理由可能由模型生成，可能存在错误。官方声明、研究结果、第三方实测、作者观点和推断应按原文分别理解；重要结论请核对原文的时间、平台、样本和限制条件。

原文版权归各来源所有。软件默认只展示摘要和原文链接，只有来源明确允许时才展示全文。

2. 来源方的更正与下架

站点提供反馈入口，可提交来源补充、链接更正、内容纠错及下架请求。正式处理方式与对外联系方式待运营者上线前确认。

3. 使用本站的数据

个人阅读、组织内部使用、公开转载、商业产品及批量再分发的具体使用范围，均待运营者上线前确认。框架代码的 MIT 许可不等于第三方原文的转载许可。

4. 接口与频率

软件提供匿名只读的 RSS、公开 API 和 MCP。客户端应按响应中的缓存时间轮询；收到 429 或 503 时遵守 Retry-After，避免并发重试。正式运营时的访问约定待上线前确认。

5. 上线前待确认

运营者需补全运营信息、允许的使用范围、纠错与版权请求流程，以及服务可用性和责任范围的正式说明。
