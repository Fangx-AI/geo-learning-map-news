    获取、阅读、重用：人工智能搜索代理如何弯曲网络规则

    人工智能搜索代理形成了一类新兴且快速增长的网络流量。像浏览器一样，它们根据用户的需求获取网页；像转码代理一样，它们会重写获取的内容；像共享缓存一样，它们会根据存储的副本回答其他用户的问题。出版商依赖的规则，如 robots.txt、Retry-After 和 Cache-Control，是为更常见的客户端编写的，因此代理的供应商决定遵循哪些规则。我们展示了一项黑箱测量研究，分析这些代理如何获取、读取和重用网页，涵盖了 OpenAI、Anthropic、xAI 和 Google 的搜索 API 以及十个服务的消费端应用程序。我们发现，OpenAI 和 xAI 不遵守 robots.txt，而且没有任何服务会执行 Retry-After。服务静默读取的内容少于源站提供的内容：OpenAI 会丢弃某些格式，没有服务会读取仅包含 JavaScript 的内容，而 xAI 只读取网页的前 0.5 MB 内容……
